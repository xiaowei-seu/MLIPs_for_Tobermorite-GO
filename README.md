# MLIPs for Tobermorite/GO
This repository provides machine learning interatomic potentials developed for Tobermorite/GO composite using DP, NEP, NequIP and MACE frameworks by Weihuan Li, Chenchen Xiong, Wentao Chen, Yang Zhou.

These potentials can be deployed in LAMMPS, demonstrating both excellent accuracy and high efficiency for large-ecale molecualr dynamics simulations of interface between Tobermorite and graphe oxide.

The corresponding training configs were also provided.
